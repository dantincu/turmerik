# Desert Sand

A light VS Code theme in warm sand, terracotta, and olive tones — the feeling of sun-bleached dunes.

## Install locally

1. Copy this folder into your VS Code extensions directory:
   - Windows: `%USERPROFILE%\.vscode\extensions\desert-sand-theme`
2. Reload VS Code.
3. Open the Command Palette → `Preferences: Color Theme` → select **Desert Sand**.
