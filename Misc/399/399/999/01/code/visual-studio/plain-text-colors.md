# Visual Studio Plain Text colors (all 90 themes)

Tools > Options > Environment > Fonts and Colors > Show settings for: **Text Editor** > Display items: **Plain Text**.
Set "Item foreground" / "Item background" to the RGB values below for whichever theme is currently selected
(this is a single global setting, not per-theme, so it must be reset each time you switch themes).
